## Custom Embedded SVG Icon Variants

These are the same badges as above, rebuilt with a base64-encoded SVG passed directly into `logo=`, instead of a `simple-icons` slug. Same categories, kept together here since they are a distinct technique: full control over the icon art and color, at the cost of a much longer URL that is harder to read, edit, or debug than a plain slug.

### Local SVG File Badges (repo-hosted, not shields.io)

These reference an SVG file committed to the repository instead of an external service, so they render only if the file exists at that path relative to the README:

```md
![Recommended](./recommended-badge.svg)
![Last.fm](lastfm-badge.svg)
```

Use this pattern when you need a fully custom badge design that shields.io cannot produce, such as multi-color gradients or non-standard shapes. Keep the SVG files small and check them into the repo alongside the README.

## Bonus: Custom Colored-Text Badges

Shields.io static badges let you set any label, message, and color combo:

```md
![Label](https://img.shields.io/badge/LABEL-MESSAGE-COLOR)
```

Examples:

```md
![Custom Blue](https://img.shields.io/badge/Note-Read%20Me%20First-2962FF?style=for-the-badge)
![Custom Pink](https://img.shields.io/badge/New-Feature-FF2D95?style=for-the-badge)
![Custom Gold](https://img.shields.io/badge/Tip-Star%20This%20Repo-FFD700?style=for-the-badge&logoColor=black)
```

Colors accept hex codes (`FF0000`) or named values (`brightgreen`, `critical`, `informational`, `success`, `important`, `blue`, `orange`).
